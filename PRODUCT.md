# Riyasat
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Delegated by the user: Next.js, TypeScript, PostgreSQL/Supabase authentication and private storage. Mobile-friendly web application.

## Users
Indian property owners, family members and property managers. Each owner group has a private workspace. Owners administer; managers operate assigned properties; viewers inspect assigned property finances.

## Product Purpose
Trace rent due and received, expenses, deposits, bills and retained money to their source records. Visually organise mixed-use buildings into floors and rentable units, or manage an individual flat with one automatically created rentable unit.

## Operating Context
Cash, UPI and bank-transfer recording; partial payments; refundable deposits; monthly rent; shared maintenance; family financial transparency. India-wide configurable tax recording, no automatic legal filing.

## Capabilities and Constraints
Complete core web application, floor/unit schematic builder, leases, balanced ledger, approvals, maintenance, imports, reconciliation, reports and private workspaces. No tenant portal, payment gateway, 3D plans or shareholder entitlement calculations in v1.

## Brand Commitments
Project name: Riyasat. Plain, transparent financial language.

## Evidence on Hand
The core web application and server financial commands are implemented. The application requires configured hosted authentication and storage; new workspaces contain no property, tenant or financial records. There is no demonstration mode or sample-data seed. No customer records, production credentials, testimonials, or remote deployment have been supplied. Hosted setup requires the included Supabase migration and environment variables. Live security, deployment and backup restoration remain unverified.

## Product Principles
- A balance must be traceable.
- Deposits are liabilities, not income.
- Access is enforced on the server.
- Corrections preserve posted history.
- Simple operational screens over a rigorous ledger.

## Accessibility & Inclusion
Keyboard-accessible controls, readable contrast, mobile layouts and non-colour status labels.
